# XimTier v3 — design.md (v1 디자인 시스템 참고 가이드)

> v3는 **v1(배포 전 백업)의 디자인 시스템**을 따른다. 이 문서는 v1의 brand-dna.json에서 추출한 디자인 토큰을 v3 구현용으로 정리한 것이다. 내용/구조는 새로 짜되(슬라이드 5번 중심), 룩앤필은 이 가이드를 준수한다.

## 1. 브랜드 정체성 (v1 기준)
- **이름**: XimTier
- **포지셔닝**: Decision Intelligence, Proven by Numbers (Post-LLM Decision Intelligence Platform)
- **태그라인(ko)**: "LLM이 못 푸는 수치를, 우리가 증명한다"
- **내러티브 앵커**: "ChatGPT가 설명한다면, XimTier는 증명한다"
- **보이스**: 엔터프라이즈 신뢰 · 테크 모던 · 단호한 단언 · 수치 우선

## 2. 색상 (Airbnb 시스템 — 단일 액센트)
| 토큰 | 값 | 용도 |
|---|---|---|
| primary (Rausch) | `#ff385c` | 유일 액센트, 주요 CTA |
| primary_active | `#e00b41` | CTA hover/active |
| canvas | `#ffffff` | 페이지 기본 배경 |
| surface_soft | `#f7f7f7` | 카드/섹션 보조 배경 |
| ink | `#222222` | 제목 텍스트 (Pure black `#000` 금지) |
| body | `#3f3f3f` | 본문 텍스트 |
| muted | `#6a6a6a` | 보조 텍스트 |
| hairline | `#dddddd` | 구분선/테두리 |

**다크 섹션** (Hero·강조부): 딥 네이비 `#0a1124` / `#16325C` 배경 + 흰 글자. 단, 액센트는 여전히 Rausch 또는 청록 그라데이션(`#2563EB`→`#00C8C8`) 중 v1에서 쓰던 것만.

## 3. 타이포그래피
- **폰트**: `'Airbnb Cereal VF', Circular, Inter, system-ui, 'Apple SD Gothic Neo', sans-serif`
- **mono**: `'JetBrains Mono', ui-monospace, monospace`
- **한글 규칙**: `word-break: keep-all`, `overflow-wrap: anywhere`
- 주요 스케일: display_xl 28px/700, display_lg 22px/500, body_md 16px/400, badge 11px/600, uppercase_tag 8px/700 (letter-spacing 0.32px, uppercase)
- **기술 키워드는 영문 유지**: Reverse What-If, SHAP, R², p-value, MAE, RMSE, Decision Intelligence, Post-LLM

## 4. 공통 클래스 (v1 home에서 쓰던 패턴 — v3에서 재사용)
- 섹션: `section-dark` (다크), `surface-canvas` / `surface-soft` (라이트), `section-pad` / `section-pad-compact`
- 제목: `h-display`, `h-section`, `type-display-xl/lg/sm`
- 본문: `type-body-md`, `text-body-airbnb`, `text-muted-airbnb`
- 액센트: `text-rausch`, `text-brand-grad` (그라데이션), `type-uppercase-tag`
- 버튼: `btn btn-grad` (그라데이션 CTA), `btn btn-ghost` (고스트)
- 카드: `card-airbnb`, `shadow-card-hover`
- eyebrow: `<div class="eyebrow"><span class="dot"></span>...</div>`

## 5. Anti-Patterns (v1 — 절대 금지)
- ❌ "혁신적/최첨단/차세대" 같은 공허한 형용사
- ❌ 이모지로 신뢰감 대체 (CTA·헤드라인에 이모지 금지)
- ❌ Rausch(#ff385c) 외 액센트 색 추가 (단일 voltage 원칙) — 단 다크 섹션의 청록 그라데이션은 v1에서 쓰던 것이라 허용
- ❌ Pure black(#000) — ink(#222222)만
- ❌ 여러 단계 shadow tier — 단일 tier(card hover)만
- ✅ 화면당 단호한 Primary CTA 1개 필수
- ✅ 첫 0.5초 안에 다음 행동 식별 가능해야 함

## 6. v3 구성 방향 (이 문서의 적용 대상)
- **첫 화면(Hero) = PPTX 슬라이드 5번 "핵심 기술력"** 내용:
  - 헤드라인: "AI가 데이터를 이해하고, 최적의 전략을 제시 — 더 빠르고 더 정확한 의사결정"
  - **6단계 워크플로우**: ① 지능형 스캔·스마트 탐색(WhatDataAI) ② 3대 스마트 분석(Meeting·설문·SNS) ③ 60여 종 알고리즘 경쟁 ④ Reverse What-If 목표 설정 최적화 ⑤ 비전문가 중심 XAI & AI Q&A ⑥ 최적화 의사결정·실행 가이드
  - 하단: 자연어 Q&A 리포트 / 음성 질의 대화형 답변 + "심티어만의 차별화 가치"
- 이 디자인 가이드(v1 톤)를 적용하여 v3의 Hero부터 구현한다.
